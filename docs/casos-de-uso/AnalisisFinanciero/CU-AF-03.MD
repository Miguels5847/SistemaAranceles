# Caso de Uso: Configurar TMR y calcular TIR y VAN

Identificador: CU-AF-03
Actor primario: Administrador

## Flujo Principal

1. Configurar tasa bancaria, inflación y riesgo
2. TMR = Tasa + Inflación + Riesgo
3. Calcular TIR
4. Calcular VAN
5. Mostrar indicadores

Reglas
RN-163: TMR = suma lineal
RN-164: TIR ≥ TMR = viable
RN-165: VAN = 0 objetivo
