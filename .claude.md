# Claude / Codex Project Notes

Guia corta para trabajar en `SistemaAranceles` sin romper el flujo actual.

## Reglas de trabajo

### Comunicación
- Be concise · bullets > prose · code > explanations
- No restating input · no preamble · minimal tokens
- Do not explain unless asked
- Respuestas finales tipo 1 línea ("X actualizado") salvo decisión técnica no inferible

### Commits / Git
- **NO commit, push, reset, checkout destructivo ni borrar ramas sin pedido textual del usuario.**
- **NO incluir `Co-Authored-By: Claude`** ni cualquier otro tag de co-autor en los commits. El usuario es el único autor visible.
- Estilo de mensaje: 1 línea de título + cuerpo opcional describiendo el "porqué". Sin emojis.
- Cuando un KAN requiere SQL en Supabase: **PAUSAR** la ejecución, presentar el script, esperar confirmación textual del usuario con el resultado, y recién después seguir codeando o cambiar de rama.

### Estilo de código
- No agregar features/refactors/abstracciones más allá de lo pedido.
- No comments en código salvo el "porqué" no obvio.
- Reutilizar lo existente antes de crear; antes de borrar/renombrar, grep los referenciantes.
- Antes de cambiar código: leer el módulo afectado, buscar referencias con `rg`, y respetar patrones locales.
- Para editar archivos usar parches (Edit), no sobrescrituras improvisadas (Write).

### Build / WPF
- Para cambios WPF o Application ejecutar:

```powershell
dotnet build .\src\Presentation\SistemaAranceles.Presentation.csproj
```

- Si el build falla por archivo bloqueado (`MSB3027` / `.dll` en uso), cerrar la app WPF y repetir.
- No inyectar `ContextoAplicacion` directamente en ViewModels. Crear scope local con `IServiceProvider.CreateScope()`.
- Permisos en UI/runtime: usar `SesionActual.TienePermiso("MOD.ACCION")` y bypass admin con `SesionActual.EsAdministrador`.
- Mantener Clean Architecture: `Domain`, `Application`, `Infrastructure`, `Presentation`.

## UI WPF: gotchas importantes

### Combos en cascada

Cuando cambia `Carrera` y se recargan `Escenarios`, limpiar la seleccion antes de reemplazar la coleccion y usar bandera de supresion:

```csharp
_suprimirRecarga = true;
try
{
    EscenarioSeleccionado = null;
    Escenarios = new ObservableCollection<EscenarioProyeccion>(lista);
    EscenarioSeleccionado = Escenarios.FirstOrDefault();
}
finally
{
    _suprimirRecarga = false;
}
```

Las `partial void OnXChanged` deben salir si `_suprimirRecarga` o `EstaCargando` esta activo.

### Texto formateado

Si `StringFormat` en `TextBlock.Text` no aplica bien, exponer una propiedad `Display` preformateada desde el DTO/ViewModel.

### DataGrid

Usar dimensiones estables:

```xml
CanUserResizeColumns="False"
CanUserSortColumns="False"
CanUserReorderColumns="False"
HeadersVisibility="Column"
GridLinesVisibility="Horizontal"
AlternatingRowBackground="#F8F9FF"
```

Cuando un `DataGrid` esta dentro de `ScrollViewer`, puede capturar la rueda del mouse. En `MantenimientoView.xaml.cs` ya existe el patron `DataGrid_PreviewMouseWheel` para reenviar el scroll al contenedor.

### Ventanas modales

No asumir `Application.Current.MainWindow` como owner. Puede referenciar la propia ventana modal. Buscar ventana activa distinta de la modal.

### Vistas nuevas (gotchas)

- **Constructor de la View sin parámetros**. WPF instancia desde `DataTemplate` con `new View()`. Inyectar VM por parámetro causa `MissingMethodException` y cuelgue. El `DataContext` lo asigna el `DataTemplate` automáticamente al contenido del `ContentControl`.
- **Registrar `DataTemplate` en `MainWindow.xaml`** apuntando `{x:Type vm:NuevoViewModel}` → `<v:NuevoView/>`. Sin esto, `ContentControl` muestra el `ToString()` del VM (FQN del tipo).

### Bindings `IsEnabled` / bool

- `IsEnabled` espera `bool`, no `Visibility`. **Nunca** usar `StringToVisibilityConverter` / `BoolToVisibilityConverter` / `InverseBoolToVisibilityConverter` en `IsEnabled`.
- Patrón correcto: exponer propiedad calculada `bool` en el VM (ej. `FormEsModoManual`, `FormPorcentajeMatriculaEditable`, `NoEstaGuardando`) y notificar cambio en `partial void OnXChanged` del campo origen.
- Para invertir un bool en XAML existe `InverseBoolConverter` (no usar la versión `*ToVisibility*`).

### Parser decimal robusto

Para inputs monetarios usar el parser flexible que ya existe en `CapitalTrabajoViewModel.TryDecimalFlexible` (mismo método replicado en `DemandaIngresosViewModel.TryDecimal`). Acepta: `1495`, `1495.50`, `1495,50`, `1.495,50`, `1,495.50`, `$ 1.495,50`. **No** usar `Replace(",", ".")` simple — falla con miles.
