# Convenciones críticas (NO ROMPER)

## Permisos & seguridad

- Permisos en runtime: **siempre** `SesionActual.TienePermiso("MOD.ACCION")` — nunca BD per-op
- Códigos reales: `US.{CREAR,EDITAR,ELIMINAR,VER}`, `INF.{VER,EDITAR}`, `AUD.VER`, `AF.VER`
- `_sesionActual.EsAdministrador` bypass para admin
- Hash contraseñas: `IServicioHash` (BCrypt)

## Capa de datos

- DbContext **`Scoped`** (registrado así en DI)
- ViewModels async crean scope propio: `using var scope = _serviceProvider.CreateScope()` — NUNCA inyectar `ContextoAplicacion` directo en VM/servicio (causa deadlock con pooler 6543)
- Soft delete: `esta_activo=false` + `eliminado_en` + `eliminado_por_usuario_id`. Hard solo si `Estado=Inactivo`
- Sin N+1: batch con `WHERE col = ANY(@ids)`
- Transacciones: `IUnidadTrabajo.{Iniciar,Confirmar,Revertir}TransaccionAsync`
- Auditoría: fire-and-forget vía `IAuditoriaServicio.RegistrarAsync` (no bloquea ni revierte)

## Naming

- Interfaces: `IRepositorio*`, `IServicio*`
- Use cases: una clase por caso, método `EjecutarAsync`
- Commands: `*Command`. Queries: `*Query`. Use cases generales: `*UseCase`

# Patrones de UI (WPF + CommunityToolkit.Mvvm)

## Bindings — gotchas críticos

### `[ObservableProperty]` con propiedades string derivadas

**NO** notifica propiedades computadas. Para propiedades `Texto*` derivadas:

```csharp
[ObservableProperty]
[NotifyPropertyChangedFor(nameof(TextoEstudiantesCarrera))]
private decimal _estudiantesCarrera;

public string TextoEstudiantesCarrera => string.Format(CultureInfo.CurrentCulture, "{0:N0}", EstudiantesCarrera);
```

### `StringFormat` en `TextBlock.Text` puede fallar silenciosamente

Si `{Binding X, StringFormat={}{0:N2}}` no respeta el formato (muestra entero cuando debería mostrar decimales), **bypass**: expone una propiedad `string` pre-formateada en el VM y bindea directo:

```xml
<TextBlock Text="{Binding TextoX}"/>  <!-- en vez de StringFormat -->
```

### Combos en cascada (Carrera → Escenario → Período)

WPF reescribe `SelectedItem` cuando `ItemsSource` cambia y la referencia anterior no existe en la nueva colección → cascade roto, vista en blanco.
**Patrón correcto** (resetear ANTES de reemplazar colección):

```csharp
_suprimirRecargaAutomatica = true;
try
{
    EscenarioSeleccionado = null;            // 1. limpiar selección
    Escenarios = new ObservableCollection(lista); // 2. reemplazar
    EscenarioSeleccionado = Escenarios.FirstOrDefault(); // 3. seleccionar primero
}
finally { _suprimirRecargaAutomatica = false; }
```

Las `partial void OnXxxChanged(value)` deben chequear `_suprimirRecargaAutomatica` y hacer `return` si está activo.

### Owner de Window modal

**NO** usar `Application.Current.MainWindow` como Owner — WPF puede haber reasignado `MainWindow` a la propia ventana modal → `InvalidOperationException: La propiedad Owner no se puede establecer en sí misma`.
**Patrón correcto**:

```csharp
var owner = System.Windows.Application.Current?.Windows
    .OfType<Window>()
    .FirstOrDefault(w => w.IsActive && !ReferenceEquals(w, ventana));
if (owner is not null) ventana.Owner = owner;
```

### `using SistemaAranceles.Application.*` en VM ⇒ `Application.Current` falla

El namespace `Application` shadowea `System.Windows.Application`. Calificar siempre:

```csharp
System.Windows.Application.Current?.Windows...
```

### DataGrid con columnas dinámicas (pivot)

Generar columnas en code-behind usando `Binding($"ValoresPorPeriodo[{i}]")` para arrays/listas. Modelo de fila expone `decimal[]` o `IReadOnlyList<decimal>`. Ver [ResumenSueldosWindow.xaml.cs](src/Presentation/Views/CargosFacultad/ResumenSueldosWindow.xaml.cs).

### DataGrid estable (sin "saltar" columnas)

Siempre incluir:

```xml
CanUserResizeColumns="False" CanUserSortColumns="False" CanUserReorderColumns="False"
HeadersVisibility="Column" GridLinesVisibility="Horizontal"
AlternatingRowBackground="#F8F9FF" BorderBrush="#C5CAE9"
```

La columna `*` necesita `MinWidth` para no colapsar.

## Sueldos (KAN-20, antes "Sueldos y Planta Central")

- View: [CargosFacultadView.xaml](src/Presentation/Views/CargosFacultad/CargosFacultadView.xaml) — **vista única read-only**, NO CRUD
- VM: [CargosFacultadViewModel.cs](src/Presentation/ViewModels/CargosFacultad/CargosFacultadViewModel.cs)
- Header: 4 selectores (Carrera · Escenario · Período · EstudiantesUA editable) + botones [Generar/Recalcular] [Resumen Sueldos]
- Datos derivados de:
  - Cargos: `IRepositorioCargoFacultad` (con fallback a otra carrera si la seleccionada no tiene)
  - Estudiantes: `IRepositorioProyeccionEstudiantes` por carrera+escenario, suma `Detalles.TotalEstudiantes` filtrados por `PeriodoAcademicoId`
  - Inflación: `IRepositorioInflacionAnual` (rango anioBase..anioPeriodo)
  - Año base: viene de `proyeccion.AnioBase` (NO constante)
- **Carreras del combo**: solo las que tienen al menos una `ProyeccionEstudiantes` activa ([ListarCarrerasConProyeccionQuery.cs](src/Application/UseCases/CargosFacultad/ListarOpcionesSueldosQuery.cs))
- **Estudiantes UA**: editable, default `285`, **override de sesión** (no se persiste). Se usa en `CalculoCargosFacultad.CalcularPeso` para cargos administrativos no-fijos
- **EstudiantesCarrera display**: `N0` (entero) — "no hay 68.33 estudiantes". Internamente `decimal` para cálculos
- **Inflación encadenada por año** (NO acumulada en display):
  - P1-año: hereda factor del P2 del año anterior
  - P2-año: aplica `× (1 + infl_año/100)` al factor previo
  - Implementación: `CalcularFactorEncadenadoAsync` itera años desde `anioBase` hasta `anioPeriodo`; multiplica por `(1+pct/100)` para cada año completo previo, y para el año del período solo si `numeroPeriodo >= 2`

## Cálculo de cargos (compartido)

Helper estático: [CalculoCargosFacultad.cs](src/Application/UseCases/CargosFacultad/CalculoCargosFacultad.cs)

- `CalcularPeso(cargo, estCarrera, estUA)`:
  - Cargos exclusivos (peso=1.0): docentes (`EsCargoDocente=true`), "Director de Carrera", `TipoCargo` con "dedicacion exclusiva"
  - Resto: `est_carrera / (est_UA + est_carrera)`, redondeado a 4 decimales
- `D13 = sueldo / 2` · `D14 = valorBase / 2` · `Vacaciones = sueldo / 4`
- `FondoReserva = sueldo × 0.0833` · `AportePatronal = sueldo × 0.1115`
- `CostoBaseSemestral = (sueldo + FR + AP) × 6 + D13 + D14 + Vacaciones`
- `CostoTotalSemestral = CostoBase × peso × personas × factorInflacion`

## Inflación (KAN-10..12)

- Tabla `inflacion_anual`: `decimal(7,4)` percent, `tipo_fuente ∈ {importada, estimacion}`
- Importada > Estimación cuando hay ambas para el mismo año (`OrderBy(IsEstimacion ? 1 : 0).First()`)
- Convertir % a factor: `1 + (pct / 100)`. Anti-deflación: `Math.Max(factor, 1m)`

## 3. Estado actual del código vs. Requerimientos Docente

### ✅ Implementado (Lógica en `ConsolidadorProyeccionEstudiantes.cs:149-162`)

- **Redondeos:** Uso de `CEILING` para el Total de docentes: `dTot = Ceil(fila15[p] / hDoc)`.
- **Distribución:**
  - `CEILING` para Magísteres (Mgs): `Ceil(dTot * 0.60)`.
  - `CEILING` para PhD: `Ceil(mgs * 0.40)`.
- **Validaciones:**
  - Parcial residual no negativo mediante `Math.Max(0, dTot - mgs - phd)`.
  - Invariante documentada: `PhD + Mgs + Parcial == Total`.
  - El Tab 4 (Consumo) ya aplica `Ceil` para el conteo de personas.

### ❌ Pendiente (Brechas Críticas)

- **Medio Tiempo (MT):** La fila se emite con `new int[totalPeriodos]` (ceros) en `ConsolidadorProyeccionEstudiantes.cs:169`. La diferencia decimal cae erróneamente toda al Parcial.
- **Parámetros Faltantes:** No existen las constantes ni inputs para `HorasMediaJornada (12)` y `HorasParcial (6)`.
- **Tarifa TP:** En `CargosFacultad`, el Tiempo Parcial se paga como sueldo fijo; falta implementar el cálculo por **tarifa horaria**.
- **Check de Cobertura:** La invariante actual valida personas, pero no horas. Falta validar:
  `PhD×18 + Mgs×18 + MT×12 + TP×h ≥ horas asistidas`.
- **Hardcoding de Malla:** Los inputs `DocHorasSemestralesDefault` están cableados en código, replicando el problema de rigidez del Excel (`1 Estudiantes!B16:I16`).
- **Reglas de Negocio:** Las reglas `RN-71/RN-72/RN-73` del documento `CU-ES-03.MD` están documentadas pero no ejecutadas.
