## WPF: Gotchas Importantes

### DataTemplates

Cada ViewModel que se asigna a `PaginaActual` necesita un `DataTemplate` en `MainWindow.xaml`.

La View debe tener constructor sin parametros; WPF la instancia desde XAML y el `DataContext` lo asigna el `ContentControl`.

### Menu Principal

El menu lateral se construye en `MainViewModel.ConstruirMenu()`.

Estado actual:

- `ItemMenu` hereda de `ObservableObject`.
- Cada item tiene `EstaSeleccionado`.
- `SeleccionarMenu(titulo)` desmarca todos y marca el item activo.
- `MainWindow.xaml` pinta el item activo con fondo resaltado, barra amarilla y sombra.
- Los textos largos usan `TextBlock` con `TextWrapping="Wrap"`, `TextTrimming="CharacterEllipsis"`, `MaxWidth="166"` y tooltip.

Cuando se agregue un modulo nuevo:

1. Agregar item en `ConstruirMenu`.
2. Agregar metodo de navegacion.
3. Llamar `SeleccionarMenu("Titulo exacto")` al navegar.
4. Registrar `DataTemplate` si `PaginaActual` apunta a un VM nuevo.

### Timer de Sesion

Archivos:

- `ServicioInactividad.cs`.
- `App.xaml.cs`.
- `MainViewModel.cs`.
- `MainWindow.xaml`.

Reglas actuales:

- El timeout viene de `Session:TimeoutMinutes`.
- `ServicioInactividad.TiempoRestante` expone el restante actual.
- `TiempoRestanteActualizado` se emite en tick, inicio y reset de actividad.
- `MainViewModel.TiempoRestanteSesion` se inicializa desde `TiempoRestante`.
- Al recuperar foco, `App.xaml.cs` ignora eventos de actividad durante 2 segundos para evitar que el timer salte a `44:59` solo por cambiar de ventana.

No volver al patron de "ignorar solo el primer input tras activacion"; se observo inestable por eventos multiples de foco/entrada.

### Combos en Cascada

Cuando cambia `Carrera` y se recargan `Escenarios`, limpiar seleccion antes de reemplazar la coleccion y usar bandera de supresion:

```csharp
_suprimirRecarga = true;
try
{
    EscenarioSeleccionado = null;
    Escenarios = new ObservableCollection<EscenarioProyeccion>(lista);
    EscenarioSeleccionado = Escenarios.FirstOrDefault();
}
finally
{
    _suprimirRecarga = false;
}
```

Las `partial void OnXChanged` deben salir si `_suprimirRecarga` o `EstaCargando` esta activo.

### `IsEnabled` y Converters

`IsEnabled` espera `bool`. No usar converters de `Visibility` en `IsEnabled`.

Usar propiedades booleanas en el VM, por ejemplo:

- `FormEsModoManual`
- `FormPorcentajeMatriculaEditable`
- `NoEstaGuardando`
- `RatioFormMesesEditable`
- `RatioFormAdicionalFijoEditable`

### Decimales

Para inputs monetarios usar parser flexible existente en ViewModels como `TryDecimalFlexible` o `TryDecimal`. Evitar `Replace(",", ".")` simple porque falla con separadores de miles.

### DataGrid y Scroll

Usar dimensiones estables y estilos existentes:

```xml
HeadersVisibility="Column"
GridLinesVisibility="Horizontal"
AlternatingRowBackground="#F8F9FF"
```

Si un `DataGrid` dentro de `ScrollViewer` captura la rueda del mouse, revisar el patron `DataGrid_PreviewMouseWheel` en `MantenimientoView.xaml.cs`.

### Modo de calculo

- Modo unico fijo: **Compatible Excel** (reproduce VAN~=0 / TIR~=9.54% del Excel del tutor). Se elimino el modo "Tecnico" (anual ortodoxo) porque la tesis se compara directamente contra el Excel; junto con el se quito el selector de la UI, el enum `ModoCalculoFinanciero` y `ConsolidadorFlujosFinancieros`.
- Convencion: flujos SEMESTRALES, VAN con `=VAN()` de Excel (periodo 0 tambien descontado), SIN recuperacion de capital de trabajo.

### Reglas financieras criticas

- **Becas**: se modelan como **descuento de ingreso** (costo = 0), nunca como costo. No eliminarlas; coincide con el Excel. Se evito un doble conteo previo de becas.
- **TIR**: TIR normal (no TIRM). Con multiples cambios de signo / multiples raices, se reporta la raiz **mas cercana a la TMR**.
- **Periodo de recuperacion**: no asumir que siempre se resuelve; manejar estados de no-convergencia.
- **Punto de Equilibrio**: se calcula con el **ultimo periodo proyectado** (no promedio).
- **Arancel Optimo (biseccion)**: parametros (tolerancia VAN, max iteraciones, etc.) configurables en Datos Institucionales (5 params nuevos KAN-44). Mensaje claro al alcanzar "maximo de iteraciones". Estados de convergencia explicitos.
- Dashboard ya no exporta CSV (se quito).
- "Costo Carrera" como opcion = informacion **referencial** (no rompe el analisis al seleccionarla).
